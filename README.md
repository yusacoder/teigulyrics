# TeiguLyrics

Akame ga Kill! evreninden ilham alan, özgün anime müzikleri ve sözleri için hazırlanmış statik hayran projesi.

## Çalıştırma

Projeyi statik bir web sunucusuyla yayınlayın (ör. GitHub Pages). `index.html`, `style.css`, `app.js` ve `data.json` aynı dizinde bulunmalıdır. İçerik ve görünüm `data.json` dosyasından yönetilir.

## İçerik düzenleme

- `tracks`: Parça kartları, karakter etiketi ve renk.
- `themes`: Projenin ilham başlıkları.
- `appearance`: Kırmızı vurgu renkleri.
- `site`: Başlık, açıklama ve alt bilgi.

Parça kartlarındaki oynat simgeleri görsel tasarım öğesidir; ses bağlantıları eklendiğinde oynatıcı davranışı ayrıca bağlanabilir.

Akame ga Kill! ve karakterleri ilgili hak sahiplerine aittir. TeiguLyrics bağımsız bir hayran projesidir.
